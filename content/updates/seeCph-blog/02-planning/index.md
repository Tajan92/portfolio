Creating user stories helps establish a clearer grasp of the project scope and makes future analysis much more straightforward. I started by mapping out a rough initial domain model, keeping in mind that it will naturally evolve as the project progresses.

The primary focus is identifying the core entities, their relationships, and the key interactions users will have with the system. This foundation ensures that subsequent architectural decisions and database designs align with actual requirements.
